# Maintainers

Frontrunner is maintained by [Furls Digital Ltd](https://furls.co.uk).

That is the whole list. Decisions about architecture, scoring and the data
contract are made there.

## Contributing

Pull requests and issues are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
There is no contributor ladder, no review rota and no promotion criteria,
because there is no team for those to describe. If that changes, this file
changes with it.

## Upstream

Frontrunner is a fork of [career-ops](https://github.com/santifer/career-ops)
by [@santifer](https://github.com/santifer), whose work the scoring rubric,
file formats and much of the pipeline still come from.

He does not maintain Frontrunner and has no involvement in it. Please do not
send him issues, security reports or pull requests about this project — see
[SUPPORT.md](SUPPORT.md) and [SECURITY.md](SECURITY.md) for where those go.
